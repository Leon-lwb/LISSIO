## 1. 定义

- **项目**：Lissio，仓库地址为 `https://codeberg.org/Horldsence/Lissio`。
- **贡献**：为纳入项目而提交的代码、文档、配置、设计、测试或其他材料。
- **维护者**：`MAINTAINERS.md` 中列出的、有权接收贡献的人员。

## 2. 授权

贡献者保留贡献的著作权。提交贡献即授予项目及其维护者全球、免版税、非独占、
不可撤销、可再许可的许可，以 Apache License 2.0 使用、复制、修改、制作衍生作品、
分发、执行和展示该贡献。

贡献者同时按照 Apache-2.0 向项目接收者授予该贡献单独或与项目结合时必然侵犯的
必要专利许可。

## 3. 权利与兼容性

贡献者声明有权提交该贡献，不侵犯第三方权利或法定义务，且已取得必要的雇主或客户
许可。贡献必须与 Apache-2.0 及 `docs/governance/open-source-and-ip.md` 兼容。

## 4. 历史贡献

2026-10-07 之前的贡献依据当时仓库发布的贡献者协议提交。该协议包含对当前源码树进行
再许可的权利。历史二进制发布物的许可不因此追溯变更。

## 5. 无附加服务

贡献不附带担保。本协议不产生雇佣、合伙、代理、支持或保密关系。

## 6. 接受与变更

提交 pull request 或以其他方式有意提交贡献即表示接受本协议。修订后的协议只适用于
修订文本发布后提交的贡献。
